# NotchMeter

A macOS menu bar app that shows Claude and Codex usage in the MacBook notch.

- **Collapsed:** small indicators on either side of the notch (5-hour session and weekly usage).
- **Expanded:** hover the notch to see usage bars and reset countdowns.

## Status

Design preview: open `preview/index.html` in a browser.

Claude usage comes first. Codex support is planned.
